# OTP Generator

A simple Python program that generates a random numeric OTP based on the length entered by the user.

## Features
- Generates random numeric OTPs
- User can choose the OTP length
- Simple and beginner-friendly Python project

## Technologies Used
- Python
- random module
- string module

## How to Run

1. Download or clone this repository.
2. Run:

python PassGenerator.py
